**Live:** https://cristian-diaz2402.github.io/CristianDiazPortafolio/

---

## Stack

| Layer | Technology |
|---|---|
| Framework | Vue 3 (Composition API) |
| Build tool | Vite 6 |
| Styling | Tailwind CSS 3 |
| Animations | AOS |
| Icons | Iconify |
| Fonts | Syne + Inter (Google Fonts) |

---

## Local development

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
